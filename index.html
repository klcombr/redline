§ 1

The trend standard

Five comparisons. Everything in REDLINE follows from these.

Specific > trendy

Design from the product, the task, and the content — not from a collection of fashionable patterns.

Purpose > decoration

Every significant visual decision must have a reason. If an element has no job, it has no place.

Clarity > complexity

First, second, third — design around what the user should notice, in that order.

Identity > template

Swap in another company’s logo. If the site still feels right, it is not yours.

Hierarchy > ornament

Primary attention, secondary information, supporting detail. If everything is emphasized, nothing is.

§ 2

Three dials

Not style choices — settings that must come from the task.

Variance, motion, and density are dials. Their values follow the product. REDLINE never raises them just to look impressive — and it will tell you when to turn them down.

§ 4

Motion & 3D, with the packs

CSS first when it is enough. Motion, Anime.js, or GSAP for purposeful animation; Three.js when 3D is the brief.

REDLINE does not force one animation library. It routes the interaction: CSS for simple state changes, Motion for declarative UI and gestures, Anime.js v4 for compact sequences and stagger, GSAP for complex timelines and scroll choreography, and Three.js for real 3D. The brief sets the dial; the product sets the right tool.

gsap-core Single tweens, eases, staggers, defaults, matchMedia. Base layer — load this one for any GSAP work.
gsap-timeline Sequences and choreography — position, nesting, playback. Loads when animation must happen in an order.
gsap-scrolltrigger Scroll-linked, pinned, scrubbed sections. Loads when the page answers to the scroll.
gsap-react React done right — useGSAP, refs, cleanup on unmount. Loads when the stack is React / Next.js.
gsap-frameworks Vue, Svelte and other frameworks — lifecycle & scoping. Loads when the stack is not React.
gsap-plugins Flip, SplitText, MorphSVG, MotionPath, Draggable, CustomEase… Loads when a tween needs a plugin.
gsap-performance 60fps — transforms only, no layout thrash, will-change done right. Loads when the animation must not jank.
gsap-utils Math helpers — clamp, mapRange, snap, wrap, random, pipe. Loads when values need mapping, not magic numbers.

MOTION ROUTER · MOTION + ANIME.JS — THE RIGHT TOOL, NOT A STACK

motion Declarative UI, gestures, layout animation, springs, scroll and React/Vue integration. Loads when the interface is component-driven and state-aware.
animejs Anime.js v4 for compact DOM, CSS, SVG, JavaScript-object and stagger sequences. Loads when a focused sequence needs a small, controllable animation engine.

THREE.JS · 3D — ONLY WHEN THE BRIEF ASKS

threejs-fundamentals Scene, camera, renderer, Object3D hierarchy, coordinates. Every 3D scene starts here.
threejs-geometry Built-in shapes, BufferGeometry, custom geometry, instancing. Loads when the scene needs shape.
threejs-materials PBR, phong, basic, shader materials — properties and tuning. Loads when surfaces need a look.
threejs-textures Texture types, UV mapping, environment maps, colour spaces. Loads when the surface needs detail.
threejs-lighting Light types, shadows, environment light, lighting performance. Loads when the scene needs depth.
threejs-shaders GLSL, ShaderMaterial, uniforms, custom visual effects. Loads when stock materials are not enough.
threejs-loaders GLTF, textures, HDR, async patterns, loading progress. Loads when there are assets to load.
threejs-animation Keyframes, skeletal animation, morph targets, mixing. Loads when the scene moves.
threejs-interaction Raycasting, controls, mouse/touch input, object selection. Loads when the scene answers to the user.
threejs-postprocessing EffectComposer, bloom, DOF, screen-space grading. Loads when the frame needs a finish.
Register plugins once Cleanup on unmount matchMedia respects reduced-motion No looping decoration Ask the dial first 3D only when asked

Remove before adding.

THE REMOVAL TEST — if removing it changes nothing about understanding or interaction, remove it. The redline here is drawn by GSAP ScrollTrigger as you scroll — one scrub, one message, nothing else.

§ 5

The method

Seven phases, in order. Shape before code.

01Understand Product, user, task, content, constraints.
02Shape Hierarchy, composition, navigation, interaction, responsive behaviour — before decorative details.
03Establish Typography, colour, geometry, spacing, density, variance, motion.
04Build Semantic structure and reusable primitives.
05Refine Hierarchy, spacing, typography, alignment, states, motion, responsive behaviour.
06Audit Usability, accessibility, responsive behaviour, performance, consistency, content accuracy, visual hierarchy.
07Distill Remove anything that does not contribute. Do not add more because the page feels empty.
