INSTALL · ONE FILE · NO DEPENDENCIES

Copy a file. Redline everything after.

REDLINE installs anywhere an agent can read markdown. Skip only the steps that do not apply to your setup — the file does the heavy lifting either way.

§ 1

Install

Three steps. The first one is downloading the file.

01

Get the pack

redline-gsap.zip — the discipline plus the two packs: eight official GSAP skills and ten official Three.js skills, ready to drop in. Plain markdown, nothing to build. Or take just the skill file from your opencode install at ~/.config/opencode/skills/redline/SKILL.md.

Download the pack (.zip) ↓ Just REDLINE-SKILL.md
02

Put it in the agent’s skills folder

Any agent that loads SKILL.md files works. Examples:

opencode · bash
$ unzip redline-gsap.zip # discipline + GSAP + Three.js packs
$ mkdir -p ~/.config/opencode/skills/redline
$ cp REDLINE-SKILL.md ~/.config/opencode/skills/redline/SKILL.md
$ cp -r skills/gsap-* skills/threejs-* ~/.config/opencode/skills/
$ # register each in the lazy-load index (one line):
$ ~/.local/share/opencode/skills-index.md → add rows

For other agents — Claude Code, Hermes, Cursor, custom pipelines — same idea: REDLINE-SKILL.md goes wherever that agent reads its skill documents, and each skills/gsap-* and skills/threejs-* folder follows the same rule. If the agent accepts plain markdown prompts, paste the file contents directly — the discipline needs no runtime.

03

Restart the session (one time)

Skills are discovered when the agent session starts. After that, just start any design task — the agent loads the discipline when the task matches its description.

§ 2

Send to Hermes

Anything you can put a SKILL.md in, REDLINE works in.

HERMES · SAME FILE

One pack, both agents.

You do not need a different version for Hermes. Send the same zip:

→redline-gsap.zip — REDLINE + 8 GSAP + 10 Three.js skills, one archive (also in ~/Downloads)
→Unzip into Hermes’ skills folder — redline/SKILL.md + gsap-*/SKILL.md + threejs-*/SKILL.md
→Register each skill in its index (if it has one), then restart the session
to: hermes
# send this
redline-gsap.zip · 19 skills inside
 
# then one instruction:

§ 3

Verify it took

The discipline proves itself on the first job.

Sanity prompt

“Design a landing page for my product. Use the REDLINE discipline.”

In working order, the agent will ask about your product before touching CSS — and will refuse to invent testimonials, stats, or features you did not provide.

Tell-tale

It asks the seven product questions before the first pixel.

If it immediately starts writing cards and gradients, it did not load the skill. Check the skills folder and index, restart, and try again.
